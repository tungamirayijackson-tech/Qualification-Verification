# Architecture decision records

One file per decision that would be expensive to reverse. Each records the alternative we
rejected and why — the technical report's "Design decisions" section (§17) is assembled from
these, and a decision without a named rejected alternative is not a decision, it is a default.

An ADR is written **when the decision is implemented**, not when it is imagined. Decisions
still ahead of us (key rotation, the public verification surface, the ledger's write path) get
their record in the week they land.
