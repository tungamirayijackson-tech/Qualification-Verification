Download signed report

The report is a PDF stating this verdict, when it was checked and its audit reference, signed by this system so it can be shown to somebody who does not take your word for it. Downloading runs the check again, so it carries its own timestamp and its own audit reference — which is what makes it evidence of a check rather than a screenshot.

Quote the audit reference if this check is ever disputed. This system does not decide whether a qualification is real — it reports that a named institution signed a statement, and whether that statement has since been withdrawn.
